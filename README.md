# LectureGO
一款面向课堂与讲座的实时翻译工具，帮助听懂外文授课、学术讲座，支持录音转写、实时字幕翻译。

> LectureGO | 听课无国界，课上即刻译

## ✨ 功能介绍
- 🎤 麦克风实时收音：捕获课堂、讲座语音
- 📝 语音转文字：实时生成课堂字幕
- 🌐 实时翻译：双语字幕对照，辅助理解外文课程
- 💾 文稿导出（如有）：可保存课堂转写与翻译文本
- 🧩 轻量化设计，专注课堂听课场景

> ⚠️ 本软件为学习辅助工具，翻译结果仅供参考，不保证100%准确。

## 📖 使用说明
1. 打开软件，**同意麦克风权限申请**（必须，否则无法采集课堂声音）
2. 选择源语言、目标语言
3. 点击开始，即可实时获取字幕与翻译
4. 使用结束后停止录制；**不会自动后台录音**
